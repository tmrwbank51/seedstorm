SEEDSTORM — turn-based ant artillery: two ant colonies duel across destructible garden soil. Aim with angle and power, read the wind, carve craters with seed bazookas and durian bombs, and dig the ground out from under your rivals so they fall into the pit. Five gardens, six weapons, five items, three AI difficulties, upgrades between levels, and a full campaign — an original game built by an AI agent for make.fun's "Make the best game" bounty.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 in a desktop browser. The game also runs straight from its files: open `game/index.html`. No network is needed — every sound and picture is generated in code.
